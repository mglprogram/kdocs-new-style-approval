# 分类口径与历史确认结论

## 三张表的分工

| 表 | 款号前缀 | 用途 |
|---|---|---|
| 十部半托管-库存管理表 | `TM-BH-` | **首选**分类来源 |
| HW品牌店铺-TEMU库存管理表 | `TM-HW-` | 十部缺失时回退 |
| SO品牌店铺-SHEIN库存管理表 | `SHEIN-SO-` | 最后回退 |

三表分类**不完全一致**（BH vs SO 共有的 560 键里 230 键不同），所以按字段逐个回退，
不做整行覆盖。原则：**十部表优先，保证口径统一**。

| TM-BH-202304-6SetA | 产品小类 | 线上共享表用带 `*2` 的写法：`女士牛奶丝双面磨毛短款短袖-六件套-黑灰粉*2` |

## 映射推导规则

用户给的括号说明表示「这个新段 = 某旧段 × N」：

| 输入 | 推导 |
|---|---|
| `202304-6SetA（202304-3BHP*2）` | 小类沿用 3BHP 配色 → `...-六件套-黑灰粉` |
| `102207-3B（102207-1B*3）` | `1B`=黑色 → `男士罗纹短袖-3黑` |
| `102105-3B（102105-1B*3）` | `1B`=黑色 → `男士速干连帽-细珠地布口罩款-3黑` |

推导出的命名**必须单独列给用户确认**再写入，不要静默采用。

## 尺码规则

- 默认 `S/M/L/XL/XXL`
- `T1036` 系列只有 `S/M/L/XL`（无 XXL）
- 具体以该段在源表里实际存在的尺码为准
